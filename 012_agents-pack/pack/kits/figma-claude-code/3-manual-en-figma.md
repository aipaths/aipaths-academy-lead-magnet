# 3 · Tu manual de marca en Figma

Con Figma conectado y `perfil-de-marca.md` en la carpeta, pegale esto a Claude Code:

```
Armá el manual de marca de mi negocio en Figma, en el archivo que tengo abierto, en una página
nueva que se llame «Manual de marca». Todo sale de perfil-de-marca.md: no inventes colores ni
letras.

1. Una colección de variables con los colores por rol: fondo, texto, apoyo, acento, texto sobre
   acento y cuadrícula. Si el perfil tiene modo claro y oscuro y mi plan de Figma permite dos
   modos, usalos. Si no (Figma gratis permite uno solo), armá dos paletas, «Claro» y «Oscuro», y
   una colección «Tema» cuyas variables apunten a una de las dos: pasar a oscuro es cambiar a
   dónde apuntan.
2. Estilos de texto con las letras del perfil: título, subtítulo, texto y comando (si hay mono).
3. Componentes: botón, título de pieza, logo de texto, fondo, texto largo y número de paso.
4. La página del manual: los colores con su hex, las letras con un ejemplo y los componentes,
   todo atado a las variables. Ningún color suelto.
5. Una pieza de prueba armada sólo con esos componentes (una miniatura, un post o una portada).

Avisame cuando esté y decime cómo paso todo de claro a oscuro.
```

**Después, pedile piezas**
- «Pasala a modo oscuro.»
- «Haceme un carrusel de Instagram de 5 láminas sobre <tema>, con el manual.»
- Si una pieza sale vacía o rara, el arreglo va en el manual, no en la pieza: «Sumale al manual una
  pieza para <lo que falta>, con las mismas variables, y volvé a armar el carrusel».
