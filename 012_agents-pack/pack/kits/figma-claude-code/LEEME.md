# Diseñar en Figma con Claude Code

> 🎥 Viene del video **Cómo diseñar en Figma con Claude Code** *(próximamente)*.
> Más videos con su parte del pack: `../../README.md` → "¿Venís de un video?".

Tres prompts para que Claude Code diseñe en tu Figma con tu marca, aunque no sepas de diseño:
primero descubrís tu marca reaccionando a opciones, después conectás Claude Code a Figma gratis y
al final le pedís el manual y las piezas.

| Archivo | Para qué |
|---|---|
| `1-descubrir-tu-marca.md` | En un chat de Claude: tarjetas para reaccionar, tu perfil y 3 direcciones. Termina en `perfil-de-marca.md` |
| `2-conectar-claude-code-a-figma.md` | En Claude Code: instala el plugin gratis Figma Desktop Bridge sólo en la carpeta de tu marca |
| `3-manual-en-figma.md` | En Claude Code: el manual en Figma, con colores atados a variables, modo claro y oscuro, y cómo pedirle piezas |
| `perfil-de-marca.md` | La plantilla del perfil, por si la querés llenar a mano |
| `ejemplo/perfil-de-marca-aipaths.md` | El perfil real que salió para AIPaths, el del video |

Funciona con Figma gratis. Lo único que necesitás: Claude (chat y Claude Code), Figma de
escritorio y Node.js 18 o más nuevo (el prompt del paso 2 te dice cómo instalarlo si no lo tenés).
